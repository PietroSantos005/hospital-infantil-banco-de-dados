# Colaboração no projeto

Projeto de autoria coletiva. Antes de uma alteração estrutural, combinar a mudança com a equipe e conferir a equivalência com os modelos do Oracle SQL Developer Data Modeler.

- Criar uma branch descritiva (`docs/ajustes`, `sql/validacoes`, etc.) quando houver mais de um colaborador editando simultaneamente.
- Manter a ordem dos scripts em `database/` para reproduzir o ambiente de testes.
- Atualizar o README e as notas de implementação sempre que uma relação, atributo ou regra mudar.
- Usar dados exclusivamente fictícios nos exemplos e nos commits; nunca anexar prontuários, senhas, tokens, dumps de produção ou evidências com dados reais.
- Não incluir screenshots de testes sem execução verificável.
- Revisar a decisão de licença com todos os autores antes de distribuir o conteúdo como projeto de código aberto.
